## 案例1（CASE001）  ✅ OK

**性别/年龄**：男 66岁
**部位**：胃食管结合部（EGJ）
**病理**：腺癌
**分期**：cT3N2M0
**分子分型**：hj_pMMR/MSS,hj_CPS≥10,hj_Her2 1+,hj_Claudin 18.2 2+/3+ ≥75%

### 各指南推荐

**CSCO**（2024）`1A类`

对于cT3N2M0（III期）EGJ腺癌，首选围手术期化疗或新辅助化疗后手术。鉴于患者HER2阴性（1+）、PD-L1 CPS≥10且Claudin 18.2高表达，若行新辅助治疗，推荐含铂双药方案（如SOX或XELOX）[1]。若术后病理证实为III期，推荐辅助化疗（SOX/XELOX）[2]。对于晚期或不可切除情况，一线推荐化疗联合免疫治疗（纳武利尤单抗或帕博利珠单抗，基于CPS≥10）[1]。Claudin 18.2高表达提示可关注相关靶向药物临床试验或获批适应症[2]。HER2阴性排除曲妥珠单抗[1]。

- 来源：csco-胃癌诊疗指南2024.md(score=0.93)、csco-胃癌诊疗指南2023.md(score=0.93)

**NCCN**（2026 v2）`不适用`

对于局部晚期（cT3N2M0）胃食管结合部腺癌，NCCN推荐围手术期化疗（如FLOT方案）或新辅助放化疗（针对GEJ癌，尤其是Siewert II/III型）后行根治性手术[3]。术后根据病理分期决定辅助治疗。若为晚期/转移性，一线治疗推荐化疗联合免疫检查点抑制剂（PD-1/PD-L1抑制剂，基于CPS≥10）[4]。Claudin 18.2靶向药（如zolbetuximab）在CLDN18.2阳性晚期患者中作为重要选择[3]。本例HER2阴性，CPS≥10，推荐化疗+免疫治疗[4]。

- 来源：nccn-gastriccancer-2026-v2-en.md(score=0.44)、nccn-gastriccancer-2026-v2-en.md(score=0.41)

**ESMO**（Pan-Asia 2024）`不适用`

对于可切除的局部晚期EGJ癌，推荐围手术期化疗（如FLOT或SOX）或新辅助放化疗[5]。术后辅助治疗依据病理结果。对于不可切除或转移性EGJ癌，一线治疗推荐化疗联合免疫治疗（PD-1抑制剂，适用于CPS≥10）[6]。Claudin 18.2阳性患者可考虑靶向治疗（如zolbetuximab联合化疗）[5]。HER2阴性患者不使用曲妥珠单抗[6]。本例患者CPS≥10且Claudin 18.2高表达，免疫治疗或Claudin 18.2靶向治疗是重要选择[5]。

- 来源：esmo-pan-asia-gastric-cancer-2024.md(score=0.55)、jgca-japanese-gastric-cancer-treatment-guidelines-2025-7th-edition.md(score=0.44)

**JGCA**（2025 7th）`不适用`

日本胃癌治疗指南强调基于TNM分期的个体化治疗。对于cT3N2M0，推荐新辅助化疗（如SOX、S-1+顺铂）或术后辅助化疗（S-1或XELOX）[7]。对于晚期胃癌，一线治疗包括化疗联合免疫治疗（PD-1抑制剂，适用于CPS≥10或MSI-H）[8]。Claudin 18.2阳性患者可使用佐妥昔单抗（zolbetuximab）联合化疗[7]。HER2阴性患者不适用曲妥珠单抗[8]。本例患者Claudin 18.2高表达，CPS≥10，免疫治疗或Claudin 18.2靶向治疗是重要选择[7]。

- 来源：jgca-japanese-gastric-cancer-treatment-guidelines-2025-7th-edition.md(score=0.44)、jgca-japanese-gastric-cancer-treatment-guidelines-2021-6th-edition.md(score=0.43)

**CACA**（2025）`1A类`

中国肿瘤整合诊治指南推荐对局部晚期EGJ癌进行新辅助化疗或围手术期化疗[9]。对于III期患者，术后辅助化疗推荐SOX或XELOX方案[10]。对于晚期胃癌，一线治疗推荐化疗联合免疫治疗（PD-1抑制剂，适用于CPS≥10）[9]。Claudin 18.2阳性患者可考虑靶向治疗[10]。HER2阴性患者不使用曲妥珠单抗[9]。本例患者CPS≥10且Claudin 18.2高表达，免疫治疗或Claudin 18.2靶向治疗是重要选择[10]。

- 来源：caca-中国肿瘤整合诊治指南-caca-胃癌2025版.md(score=0.93)、caca-中国肿瘤整合诊治指南-caca-胃癌2025版.md(score=0.93)

### 共识

- 所有指南均推荐对局部晚期（cT3N2M0）EGJ腺癌进行新辅助化疗或围手术期化疗，随后行根治性手术。
- 对于晚期或不可切除病例，鉴于患者CPS≥10，所有指南均推荐化疗联合PD-1/PD-L1抑制剂作为一线治疗选项。
- 鉴于患者HER2阴性（1+），所有指南均明确排除曲妥珠单抗的使用。

### 差异

- 新辅助治疗模式：NCCN和ESMO更强调FLOT方案或新辅助放化疗（尤其GEJ癌），而CSCO、CACA和JGCA更常用SOX/XELOX或S-1基方案。
- Claudin 18.2靶向治疗地位：JGCA和ESMO明确将Claudin 18.2阳性作为佐妥昔单抗的适应症，而CSCO和CACA虽提及但临床可及性可能受限于地区。
- 术后辅助治疗细节：JGCA和CACA更倾向于S-1单药或序贯治疗，而NCCN和ESMO更强调双药联合化疗。

## 案例2（CASE002）  ✅ OK

**性别/年龄**：男 63岁
**部位**：胃食管结合部（EGJ）
**病理**：腺癌
**分期**：T3N1M0
**分子分型**：hj_pMMR/MSS,hj_Claudin 18.2 2+/3+ ≥75%,hj_1≤CPS<5,hj_Her2 0
**既往治疗**：4周期sox+pd1
**疗效评价**：SD

### 各指南推荐

**CSCO**（2024）`1A类`

患者为EGJ腺癌cT3N1M0，经SOX+PD-1治疗后SD。CSCO指南推荐局部晚期胃癌新辅助治疗首选SOX或XELOX方案[5]。鉴于患者PD-1联合化疗有效（SD），建议继续原方案至总疗程4-6周期，随后重新评估手术可行性[1]。若评估可切除，行根治性手术（D2清扫）。术后根据病理分期决定辅助治疗。对于MSS患者，免疫治疗获益有限，但联合化疗是标准[5]。

- 来源：csco-胃癌诊疗指南2021.md(score=0.56)、caca-中国肿瘤整合诊治指南-caca-胃癌2025版.md(score=0.93)

**CACA**（2025）`2A类`

CACA指南强调EGJ癌的综合治疗。对于cT3N1M0，推荐新辅助化疗（SOX/XELOX）[1]。患者Claudin 18.2高表达（2+/3+ ≥75%），虽目前非一线标准，但提示潜在靶向机会[2]。当前核心建议是：继续SOX+PD-1治疗，密切影像评估，若肿瘤稳定或缩小且无远处转移，尽快行根治性手术[1]。术后若病理残留，需强化辅助治疗。

- 来源：caca-中国肿瘤整合诊治指南-caca-胃癌2025版.md(score=0.93)、csco-胃癌诊疗指南2021.md(score=0.56)

**NCCN**（2026 v2）`1A类`

NCCN指南推荐所有新诊断胃癌患者进行HER2、PD-L1、MSI/MMR及Claudin 18.2检测[10]。本例HER2阴性、MSS、PD-L1 CPS<5。对于局部晚期EGJ癌，推荐新辅助化疗（FLOT、SOX、XELOX等）或新辅助放化疗[9]。患者经SOX+PD-1治疗后SD，建议继续当前方案或转换为FLOT（若体能允许）以追求更深缓解[9]。若可手术，行根治性胃切除术+D2清扫。术后辅助治疗取决于病理分期[9]。

**ESMO**（2024 Pan-Asia）`2A类`

ESMO Pan-Asia指南推荐局部晚期EGJ腺癌新辅助化疗（SOX/XELOX/FLOT）或新辅助放化疗[6]。患者MSS/pMMR，免疫治疗获益有限，但SOX+PD-1显示疾病稳定。ESMO建议，若新辅助治疗后肿瘤缩小或稳定，应行根治性手术[7]。术后辅助治疗需根据病理结果决定。对于Claudin 18.2阳性患者，目前ESMO指南尚未将其纳入一线标准治疗，但推荐参与临床试验[6]。

- 来源：esmo-pan-asia-gastric-cancer-2024.md(score=0.55)、caca-中国肿瘤整合诊治指南-caca-胃癌2025版.md(score=0.93)

**JGCA**（2025 7th Edition）`1A类`

JGCA指南推荐cT3N1M0 EGJ癌新辅助化疗（SOX/XELOX）或新辅助放化疗[11]。患者经SOX+PD-1治疗后SD，JGCA指出新辅助治疗后可手术者应行根治性手术（D2清扫）[11]。鉴于MSS状态，免疫治疗在JGCA中主要推荐用于MSI-H/dMMR患者，但对于MSS患者，联合化疗是标准[12]。若新辅助治疗后肿瘤稳定，应尽快手术。术后辅助治疗根据病理分期决定，若ypStage II-III，推荐S-1或卡培他滨[11]。

- 来源：jgca-japanese-gastric-cancer-treatment-guidelines-2025-7th-edition.md(score=0.43)、csco-胃癌诊疗指南2021.md(score=0.56)

### 共识

- 所有指南均推荐对于cT3N1M0 EGJ腺癌患者，新辅助化疗（SOX/XELOX）是标准治疗，旨在缩小肿瘤、提高R0切除率。
- 指南一致同意，若新辅助治疗后评估为可切除，应行根治性胃切除术+D2淋巴结清扫，术后根据病理分期决定辅助治疗。
- 对于MSS/pMMR患者，PD-1抑制剂单药无效，但联合化疗（如SOX+PD-1）在部分指南中被推荐或作为可选方案，尤其在中国指南中证据较强。

### 差异

- 免疫治疗地位：CSCO和CACA指南对SOX+PD-1在新辅助治疗中的应用支持度较高，而NCCN和ESMO更倾向于FLOT或单纯化疗，对MSS患者免疫治疗持谨慎态度。
- Claudin 18.2靶向治疗：CACA指南提及Claudin 18.2高表达患者可考虑临床试验或后续靶向治疗，而NCCN、ESMO、JGCA目前尚未将其纳入一线标准推荐。
- 新辅助放化疗选择：JGCA和NCCN更强调新辅助放化疗在EGJ癌中的地位，而CSCO和CACA更倾向于单纯化疗，除非肿瘤侵犯周围器官。

## 案例3（CASE003）  ✅ OK

**部位**：胃下部（L）
**病理**：腺癌,印戒细胞癌

**既往治疗**：3周期sox
**疗效评价**：缩小SD

### 各指南推荐

**CSCO**（2024）`II级推荐`

患者为局部进展期胃癌（ycT3N1M0），新辅助SOX治疗后SD，建议继续完成围手术期化疗或评估手术。CSCO指南强调所有胃腺癌需进行HER2检测（I级推荐）[6]，并推荐对拟行免疫治疗者检测PD-L1[6]。虽然患者Claudin 18.2高表达，但CSCO指南中针对新辅助阶段Claudin 18.2靶向药物证据尚处于探索阶段，主要推荐基于化疗±免疫的标准方案[4]。鉴于患者心梗病史，需严格评估心脏功能耐受性，避免心脏毒性较大的药物。

- 来源：csco-胃癌诊疗指南2024.md(score=0.56)、csco-胃癌诊疗指南2023.md(score=0.93)

**CACA**（2025）`II级推荐`

CACA指南针对II-III期胃癌新辅助治疗推荐SOX或XELOX方案[1]。患者已行3周期SOX且为SD，符合继续原方案或评估手术的指征。CACA特别强调整合治疗，对于局部晚期患者，若评估可切除，建议完成围手术期化疗后行D2根治术[1]。鉴于患者Claudin 18.2高表达，CACA 2025版可能更积极地纳入Claudin 18.2相关临床试验或靶向治疗探索（如CAR-T或ADC药物）[2]，但在标准新辅助中仍以化疗为主。需结合患者心梗病史，调整化疗强度。

- 来源：caca-中国肿瘤整合诊治指南-caca-胃癌2025版.md(score=0.93)、caca-中国肿瘤整合诊治指南-caca-胃癌2025版.md(score=0.93)

**NCCN**（2026 v2）`II级推荐`

NCCN指南推荐对所有新诊断胃癌患者进行HER2、PD-L1、MMR/MSI及Claudin 18.2检测[10]。对于局部进展期胃癌（cT3-4a或N+），标准治疗为围手术期化疗（如FLOT、SOX、XELOX）或术前放化疗[10]。患者目前SD，NCCN建议继续当前化疗方案直至完成预定周期（通常4-6周期），然后重新评估手术可行性。鉴于患者Claudin 18.2高表达，NCCN指南已将其列为重要生物标志物，但在围手术期阶段，Claudin 18.2靶向药主要证据来自晚期一线治疗，新辅助应用尚属临床试验范畴[10]。

- 来源：nccn-gastriccancer-2026-v2-en.md(score=0.44)、jgca-japanese-gastric-cancer-treatment-guidelines-2021-6th-edition.md(score=0.44)

**JGCA**（2021 6th）`II级推荐`

JGCA指南强调基于TNM分期的个体化治疗[11]。对于cT3N1M0胃癌，推荐新辅助化疗（如SOX、S-1+Cisplatin）后行根治性手术[8]。患者3周期SOX后SD，JGCA认为若肿瘤未进展且无新转移，可继续化疗至总疗程结束（通常2-3个月）或根据反应决定手术时机[8]。JGCA对Claudin 18.2的关注主要在于晚期治疗，但新辅助阶段仍以化疗为主[9]。鉴于患者印戒细胞癌病理类型，JGCA提示此类患者对化疗反应可能较差，需密切监测[8]。

- 来源：jgca-japanese-gastric-cancer-treatment-guidelines-2021-6th-edition.md(score=0.44)、jgca-japanese-gastric-cancer-treatment-guidelines-2021-6th-edition.md(score=0.43)

**ESMO**（2024 Pan-Asia）`II级推荐`

ESMO Pan-Asia指南结合亚洲人群特点，推荐对于可切除的局部进展期胃癌，围手术期化疗是标准治疗[12]。对于SOX新辅助治疗后的患者，若评估为SD，建议继续完成化疗并考虑手术[7]。ESMO强调分子分型指导治疗，虽然Claudin 18.2在晚期治疗中地位上升，但在围手术期阶段，主要依据化疗敏感性[12]。患者MSS/pMMR，免疫治疗获益有限，除非PD-L1 CPS高表达（患者CPS<5，获益低）[7]。心梗病史是ESMO指南中强调的需特别管理的合并症，建议在心内科协作下优化化疗方案[12]。

- 来源：esmo-pan-asia-gastric-cancer-2024.md(score=0.55)、esmo-pan-asia-gastric-cancer-2024.md(score=0.39)

### 共识

- 所有指南均推荐对于局部进展期胃癌（cT3N1M0）采用围手术期化疗策略，患者目前SOX治疗SD，建议继续完成既定化疗周期后评估手术。
- 指南均强调分子检测的重要性，特别是HER2、PD-L1及MMR状态，以指导后续辅助或晚期治疗选择，尽管Claudin 18.2在围手术期应用尚处探索阶段。
- 鉴于患者心梗病史，各指南均隐含或明确建议需多学科协作（MDT）评估心脏风险，优化化疗方案以减少心脏毒性。

### 差异

- CACA 2025版可能更积极地探索Claudin 18.2靶向治疗在局部晚期胃癌中的新辅助应用，而NCCN和JGCA目前主要将其证据局限于晚期一线治疗。
- NCCN指南对Claudin 18.2检测的推荐级别更高，并明确列出其作为生物标志物，而CSCO和ESMO在围手术期阶段仍主要依赖化疗标准。
- JGCA对印戒细胞癌等新辅助反应较差的组织学类型有更详细的监测建议，而CSCO和CACA更侧重于整体分期和治疗流程。
